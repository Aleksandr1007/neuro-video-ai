NEURO VIDEO AI — первая версия интерфейса

Что это:
Устанавливаемое веб-приложение (PWA) для iPhone. Сейчас в архиве готов интерфейс: текстовый запрос, загрузка фото с предпросмотром, выбор стиля и формата, адаптация под мобильный экран.

Важно:
Это пока НЕ генератор видео. Кнопка честно сообщает, что движок генерации ещё не подключён. Для реальной генерации нужно развернуть backend и подключить открытую модель. Сам iPhone не сможет эффективно запускать большие видеомодели локально. Бесплатный вариант обычно требует подходящего компьютера или доступного бесплатного вычислительного ресурса; неограниченная бесплатная генерация не гарантируется.

Как открыть и установить на iPhone:
1. Разместить содержимое папки на HTTPS-хостинге (например, GitHub Pages).
2. Открыть адрес сайта в Safari на iPhone.
3. Нажать «Поделиться» → «На экран Домой» → «Добавить».
4. Запустить NEURO VIDEO AI с появившейся иконки.

Для локального просмотра на компьютере:
Откройте index.html в браузере. Установка PWA и офлайн-кэширование корректно работают после размещения на HTTPS или локальном сервере.

Файлы:
index.html — экран приложения
style.css — оформление
app.js — интерактивность интерфейса
manifest.webmanifest — настройки установки
sw.js — service worker для кэширования
icons — иконки приложения
